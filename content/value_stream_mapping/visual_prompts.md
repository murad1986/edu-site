# 🎨 Visual Prompts Library: VSM Course
## Оптимизировано для генерации процессных диаграмм и VSM карт

---

## 1. Философия Визуального Стиля

**Для VSM курса нужен инженерный/технический стиль, а не финансовый.**

**Ключевые отличия от Retail Finance:**
- **RF:** Гравюры на пергаменте, старинные бухгалтерские книги
- **VSM:** Технические чертежи, engineering blueprints, промышленные схемы

**Почему такой стиль:**
- VSM родился на заводах Toyota — это инженерная дисциплина
- Карты процессов должны выглядеть как чертежи, а не как метафоры
- Акцент на **функциональность**, а не на красоту

## 2. Style Prefix (Глобальный Стиль)

### Базовый стиль: Technical Blueprint

```text
ВИЗУАЛЬНЫЙ ЯЗЫК:

Medium: Технический чертёж / engineering blueprint на слегка состаренной
миллиметровой бумаге (#E8EEF2 — светло-серо-голубой фон с едва заметной
сеткой).

Line Work: Чёткие тонкие технические линии. Стиль промышленных схем
и инженерных чертежей. Чистые, точные, функциональные. Никаких декоративных
элементов — только то, что несёт информацию.

Color Palette: Промышленная палитра
- Blueprint Blue (#2C5F8D) — основной цвет для Value-Added действий
- Warning Red (#C5463A) — для Waste и проблем
- Neutral Gray (#75787B) — для Necessary Waste
- Flow Green (#4A9B6E) — для стрелок потока и Continuous Flow
- Caution Yellow (#E4A93A) — для Bottlenecks и предупреждений
- Grid Background (#E8EEF2) — фон миллиметровой бумаги

Typography: Технический шрифт без засечек (DIN, Helvetica Neue, Roboto).
Чёткие подписи, размеры, аннотации. ВЕСЬ ТЕКСТ СТРОГО НА РУССКОМ, кроме
устоявшихся терминов (VSM, WIP, FIFO, JIT, TOC).

Layout: Строгая инженерная композиция. Координатная сетка. Размерные линии.
Легенда в правом нижнем углу (как на чертежах). Заголовок в рамке слева
сверху (Technical Title Block).

ТИПЫ ВИЗУАЛИЗАЦИЙ:

1. PROCESS MAPS:
   - Value Stream Maps с символами VSM
   - Блок-схемы процессов (Process Flow Diagrams)
   - Spaghetti Diagrams (диаграммы движения)
   - Swimlane Diagrams

2. TIMELINES:
   - Timeline Analysis (VA time vs NVA time)
   - Lead Time Reduction визуализации
   - Before/After comparisons

3. METRICS:
   - Bar charts для метрик (Cycle Time, WIP, etc.)
   - Pie charts для Process Cycle Efficiency
   - Waterfall charts для улучшений

4. SYMBOLS & ICONS:
   - VSM standardized symbols
   - Иконки 8 типов Waste
   - Flow indicators (стрелки, коннекторы)

ТЕХНИЧЕСКИЕ ДЕТАЛИ:

Все элементы нарисованы чёткими чертёжными линиями. Символы VSM
соответствуют стандарту (Process box, Inventory triangle, Databox,
Information flow arrows).

Цвета применяются как заливка с 70% прозрачностью — чтобы видеть сетку
фона. Границы всегда чёткие синие/чёрные линии.

Стрелки — технические (прямые углы или smooth bezier curves), не
декоративные. Push arrows (полосатые), Pull arrows (контурные).

Текст аннотаций — строго горизонтальный или вертикальный (как на
чертежах), никогда не под углом.

Размерные линии показывают Lead Time, Distance, Cycle Time.

В правом нижнем углу — Technical Legend с расшифровкой символов
и цветов.

В левом верхнем углу — Title Block:
┌─────────────────────────┐
│ НАЗВАНИЕ ДИАГРАММЫ      │
│ Курс: VSM               │
│ Версия: 1.0             │
└─────────────────────────┘
```

## 7. Различия VSM vs Retail Finance Стилей

| Аспект | Retail Finance | Value Stream Mapping |
|:---|:---|:---|
| **Medium** | Гравюра на пергаменте | Технический чертёж |
| **Фон** | Состаренный бежевый | Миллиметровая сетка |
| **Линии** | Чернильные, художественные | Технические, точные |
| **Цвета** | Sepia + Teal/Red/Gold | Blue/Red/Gray/Green/Yellow |
| **Шрифт** | С засечками (Antiqua) | Без засечек (DIN) |
| **Стиль** | XIX век, купеческая книга | Инженерный чертёж |
| **Элементы** | Иконки (якорь, свиток) | Символы VSM (стандарт) |
| **Декор** | Орнаменты, рамки | Минимум, только функция |

**Почему разные:**
- RF про деньги и бизнес → исторический/финансовый стиль
- VSM про процессы и инжиниринг → технический/промышленный стиль

2. "ПОТОК (FLOW)": Свободная река. Кораблики плывут равномерно.
ТЕКСТ:
- ПАРТИИ (Застой)
- ПОТОК (Движение)
