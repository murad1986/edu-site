## 2. Style Prefix (Глобальный Стиль)

**ВАЖНО: ИНФОГРАФИКА И СХЕМЫ, А НЕ «КАРТИНКИ»**
Цель иллюстрации — **объяснить структуру или процесс**, а не создать красивую метафору.
- **ЗАПРЕЩЕНО**: Просто красивые метафоры (корабли, яблоки, весы) без данных/структуры.
- **ОБЯЗАТЕЛЬНО**: Графики, диаграммы (Bar Chart, Waterfall, Pie), блок-схемы, таймлайны (Gantt).

**Визуальный Язык:**
- **Medium**: Научная гравюра / технический чертёж XIX века на состаренном пергаменте (#F5E6D3).
- **Line Work**: Чёткие тонкие чернильные линии. Штриховка для объёма. Стиль энциклопедии (Diderot & d'Alembert).
- **Color Palette**: Sepia base + акценты:
    - Muted Teal (#4C8C8F) — для позитива / активов.
    - Brick Red (#A93226) — для негатива / долгов / рисков.
    - Antique Gold (#C9A84C) — для денег / кэша.
- **Typography**: ВЕСЬ ТЕКСТ СТРОГО НА РУССКОМ. Шрифт с засечками (Antiqua). Чёткие подписи осей, данных и блоков.
- **Layout**: Строгая композиция. Рамка (technical border).

**Типы Визуализаций:**
1. **Structure**: Стек-диаграммы (баланс), иерархии.
2. **Process**: Блок-схемы со стрелками.
3. **Data**: Waterfall chart (P&L), Bar charts (сравнение).
4. **Time**: Гант-чарты, таймлайны (CCC).

Все элементы нарисованы чёрными чернилами в технике медной гравюры 
(copperplate engraving) с детальной штриховкой (crosshatching) для 
передачи теней и объёма. Каждый объект выглядит как научная иллюстрация 
из старинного атласа — детальный, но монохромный контур.

Поверх гравюры нанесена ограниченная акварельная тонировка приглушёнными 
цветами: приглушённый бирюзовый (#4A7C8F), кирпично-красный (#A93226), 
шалфейно-зелёный (#7DCEA0), античное золото (#C9A84C). Цвета выглядят 
как полупрозрачные акварельные мазки поверх гравюры, а не как сплошные 
заливки.

Типографика — элегантный шрифт с засечками (Serif, стиль Caslon или 
Garamond). **ВЕСЬ ТЕКСТ СТРОГО НА РУССКОМ**. Переводить всё: Rent → Аренда, Labor → Персонал, Marketing → Маркетинг. Оставлять на английском только непереводимые аббревиатуры (EBITDA, P&L, COGS).

Иллюстрация обрамлена единой декоративной гравюрной рамкой. На 
изображении только объекты, символы и диаграммы — без людей и 
персонажей.
```
