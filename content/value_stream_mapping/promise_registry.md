# 📋 Promise Registry (Реестр Обещаний)

> Этот файл отслеживает все **обещания**, данные студенту в одном уроке и адресованные другому уроку.
> Агент **обязан** проверить этот реестр перед написанием каждого урока и закрыть все обещания, направленные на этот урок.

---

## Как читать таблицу

| Колонка | Значение |
|:---|:---|
| **ID** | Уникальный номер обещания |
| **Источник** | Урок, в котором дано обещание |
| **Адресат** | Урок, который должен раскрыть тему |
| **Обещание** | Что именно обещано студенту |
| **Контекст** | Как это прозвучало в тексте (цитата или пересказ) |
| **Статус** | `⬜ open` / `✅ closed` / `🔄 partial` |
