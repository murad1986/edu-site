# Visual Prompts: 1C:ERP в Q-Commerce

> Этот файл определяет визуальный язык курса. Все инфографики должны следовать этим принципам.

## 1. Style Prefix (Глобальный)

**Style Prefix**: `Technical process diagram, Blueprint aesthetic, clean ink lines, white background, isometric 3D perspective, schema style, precision drawing, no people, professional engineering look, architectural layering, accent color: corporate blue (#0055BB).`

---

## 2. Принципы Визуализации

1. **Многоуровневость (Layering)**: Всегда разделять "Слой процесса" и "Слой данных ERP".
2. **Динамика Потока**: Использовать Sequence Diagrams для сигналов.
3. **Highload Heatmap**: Подсвечивать "узкие места" системы красным/оранжевым.
4. **Масштаб**: Zoom-in от действия пользователя до записи в регистре.

---

## 3. Типы Иллюстраций

- **Structural**: Схема метаданных (Документ -> Регистры).
- **Sequence**: Путь сигнала Заказа через API и ERP блоки.
- **Layered**: Аналогия: "Физический склад" парит над "Цифровым следом в ERP".
- **Heatmap**: Скелет системы с индикаторами нагрузки на таблицы БД.

---
